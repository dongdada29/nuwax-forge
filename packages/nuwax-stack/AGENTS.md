# nuwax-stack

优先使用中文。这个仓库交付可配置到 nuwax 平台 Agent 的技能包。

- 用户最终目标是自主接单、执行、验证、恢复；M1 的只读分析仅为已交付的起点。新增自主能力必须有真实运行证据，不能以技能发布代替运行验收。
- 团队原始需求和问题文档始终只读。单向同步到用户独立台账，只允许写明确登记的自有文档 ID；即使账号对源文档有编辑权限也不得回写。
- 原文档状态与个人处理状态分开保存；来源更新不能覆盖个人进度或自动宣称问题已解决。
- 源码写入仅在明确任务及授权仓范围内进行，保留无关 WIP，优先独立工作区；日志只写已配置的独立目录。
- 不添加轮询 daemon、独立执行引擎或 IM SDK。会话和工具由现有平台提供。
- `skills/nuwax-stack/` 是唯一分发正本，平台只安装和绑定一个技能。能力以包内 references 模块按需读取，脚本放在同包 scripts 中，不恢复成多个独立发布单元。
- 验证入口：`python3 -B -m unittest discover -s tests -v`；打包预演：`python3 -B scripts/sync_platform.py --dry-run`。
- 平台同步默认离线；`--apply` 写草稿，额外 `--publish` 才发布。不要把平台 AK 或真实会话内容写入仓库。
