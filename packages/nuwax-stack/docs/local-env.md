# 本地环境准备

已有 nuwa-cli 的用户先执行 `nuwa-cli status`，查看当前电脑、服务和登录域。首次安装、升级、重新登录或服务调整属于单独运维任务，按随装 `nuwa-cli-usage` 指引处理，不为本技能包自动重配服务。

从平台所选电脑的工具实际读取目标仓，而不只验证本机 `curl localhost`。云侧通道成功后，确认根目录、分支和 HEAD 与用户开发仓一致。连到空工作区不算接入完成。

M1 需要文件读取和有界搜索；终端不是必需条件。若提供命令工具，只执行明确的本地只读操作。测试命令可以作为建议记录；测试、构建和安装依赖留给有隔离环境与对应授权的验证任务。

日志默认回在答复中。要落盘时配置例如用户指定的仓外 `audit-directory`；脚本要求路径显式传入，不默认创建用户主目录下的日志树，不为去重写目标仓。

仓库已有 `nuwa-sdlc-kit` 时遵守当前仓内规则。没安装时也能完成只读分析，不自动安装治理工具或改 hooks。
