|---|---:|---:|

**解释边界**：时间差来自执行架构差异（模型编排 vs 固定有限脚本），是移除固定工作中模型编排与
证据手工整理的流程差异，**不是模型推理速度提高 68 倍**，也不能外推到需求设计、未知故障、GUI
或整包构建。测量边界是"任务已明确 → 执行既定验收 → 证据校验 → TaskStore 完成"，
不含上层用户对话与首次配方开发成本。样本仅 3 对，不报告稳定 P90 或生产普适提速比例。
